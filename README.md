# THECLE BTP

Using this UI/UX Pro Max skill : https://github.com/nextlevelbuilder/ui-ux-pro-max-skill for design 
and this skill : https://github.com/motiondivision/motion for animations 

Create a highly premium, ultra-responsive corporate website for "EDG BTP & SERVICES", a premier construction and civil engineering company based in Abomey-Calavi, Benin. The design language must feel industrial, robust, and prestigious, utilizing a dark navy blue, charcoal gray, and sharp construction amber/gold accent color scheme with high-end modern typography.

The site must feature these precise core architectural elements:

1. HERO SECTION: A bold, cinematic introduction displaying the headline: "Bâtir l'Avenir avec Excellence". Include subtitles framing their expertise in structural concrete, building renovations, and public infrastructure. Add a primary high-contrast action button labeled "Demander un Devis BTP" and a secondary button for "Voir nos Réalisations".

2. DYNAMIC PORTFOLIO SHOWCASE: A modern portfolio grid displaying current construction project cards ("Chantiers réels au Bénin"). Include placeholders for high-resolution site photography, a structural progress metrics bar, and a tag showing the project type.

3. EMBEDDED INTERACTIVE AI SALES ASSISTANT:

- Create a floating, interactive chatbot widget on the bottom right styled elegantly with a WhatsApp branding twist, representing  AI Operational Bot.

once users scrolls down twice, the chatbot should pop open and initiate conversation with the visitor to gain their attention.

- When clicked, it expands into a sleek messaging window titled "Assistant Virtuel EDG BTP".

- The AI agent must interactively step the user through a structured intake form asking for: 

  * "Nom et Fonction"

  * "Nom de l'Entreprise / Projet"

  * "Type de Travaux" (Checkbox choices for: Gros Œuvre, Plans Architecturaux, Rénovation Complexe, Charpente Métallique)

  * "Coordonnées WhatsApp (+229)0190212876"

- The UI must visually animate each data collection step cleanly, providing a beautiful success state showing a confirmation text: "Diagnostic validé !  Monsieur le Fondateur ou un ingénieur de permanence vous recontactera sous peu."

if the Bot cannot answera a particular question, the conversation and the visitor should be forwarded to whatsapp where user can chat with human representative.

4. TRUST & SOCIAL PROOF: A designated local SEO block displaying 5-star Google review metrics placeholders to encourage verified clients to share social proof.

5. FOOTER & COMPLIANCE: Include a formal corporate footer displaying local Benin administrative credentials, physical coordinates mapped out from their Godomey/Calavi base, and a dedicated high-visibility interactive link routing mobile users directly to Google Maps using this exact endpoint: https://www.google.com/maps/place/EDG+BTP+%26+SERVICES/@6.4081539,2.2456874,17z/data=!3m1!4b1!4m6!3m5!1s0x1024a7e8b8cb074f:0x887a2db29287c5c2!8m2!3d6.4081539!4d2.2482677!16s%2Fg%2F11zb797s4n?entry=ttu&g_ep=EgoyMDI2MDYyOC4wIKXMDSoASAFQAw%3D%3D
